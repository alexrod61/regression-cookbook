# Revision rationale for the Extended Model section

## Scope
- Target chapter/file: book/13-generalized-poisson.qmd (branch Writing-for-Section-13).
- Exact section(s): NEW `## Extending the Model with Additional Regressors {#sec-generalized-poisson-extended-model}` after the S8 GOF section, ending immediately before the draft's `## Case Study 2: 99 B-Line Bus Arrivals` (replaced in S15).
- Reference chapters/files reviewed: finished Ch10's extended-model section (L5041-6415: same four-regressor spec, dummy arrangement table, extended GOF), skill.md sections 12-13 (transitions, honest decision documentation).

## What was preserved
- The draft's intent to fit an extended GP model with all four regressors; VGAM construction `genpoisson1(zero = "dispind")`.

## What changed
- The draft had no extended-model narrative for the crab case. The new section has: explicit extended mean equation with dummy indicators (eq-generalized-poisson-extended-model, reference categories Light/Both-good); executed fits in both languages with decoding parity (logLik -173.4715 both); theta persistence paragraph (0.516 -> 0.492, LRT vs extended Poisson 70.41, p = 4.8e-17); nested LR test (8.485, df 6, p = 0.205) with the executed same-split Poisson contrast (18.55, p = 0.005); an extended GOF table with Pearson 0.89, deviance 1.51 (caveat applied by reference), expected zeros 27.8 vs 34; extended observed-vs-fitted figures in both languages; and the Poisson-vs-GP SE-comparison table with the three-point inferential reading.
- The section deliberately keeps the extended specification despite LRT p = 0.205, documented in a Tip box with two stated reasons (Ch10 comparability; protocol discipline with the study-design variable table). This solves the apples-to-apples requirement from the project plan without hiding the non-significant nested test.
- GP p-value ranges in prose quote both information conventions (e.g., Colour: Dark 0.04-0.07) rather than picking one toolchain's number.

## Why the changes help
- The GP-versus-Poisson teaching payoff of the chapter is now demonstrated, not asserted: same data, same split, same regressors, doubled uncertainty, changed p-value rankings (weight_kg 0.005 -> 0.08-0.10; spine Both 0.006 -> 0.08-0.09; only colour Dark stays near significance).
- The nested-test asymmetry between the two model classes is a subtle, real phenomenon; reporting both tests on the same split keeps the chapter honest and educational.
